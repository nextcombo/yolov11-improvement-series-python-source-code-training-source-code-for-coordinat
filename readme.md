[CoordAttention introduction]

Studies on lightweight networks have shown that channel attention can significantly enhance model performance, but it often overlooks the location information that is crucial for generating selective attention maps in the generation space. Therefore, the National University of Singapore proposed a new attention mechanism designed for lightweight networks, which embeds location information into channel attention, referred to as Coordinate Attention (hereafter CA), and was published in CVPR 2021. Unlike channel attention that transforms the input through 2D global pooling into a single feature vector, CoordAttention decomposes channel attention into two 1D feature encoding processes that aggregate features along different directions. This approach allows for long-range dependencies to be captured along one spatial direction while preserving precise location information along another. Subsequently, generated feature maps are encoded separately, forming a pair of directionally aware and location-sensitive feature maps that can complementarily apply to the input feature map to enhance the representation of the target of interest. CA is simple, flexible, and efficient, capable of being inserted into classic lightweight networks (such as MobileNetV2) without introducing additional computational overhead, while improving network accuracy. Experiments show that CoordAttention not only improves classification tasks but also yields more significant enhancements for dense prediction tasks such as object detection and instance segmentation.

The paper is available at: http://arxiv.org/abs/2103.02907

The paper source code is available at https://github.com/Andrew-Qibin/CoordAttention

Model Architecture
CA is an efficient attention mechanism that incorporates positional information into the channel attention, enabling lightweight networks to focus on larger regions while avoiding excessive computational overhead. To alleviate the loss of positional information caused by 2D global pooling, the author decomposes the channel attention into two parallel 1D feature encoding processes, effectively integrating spatial coordinate information into the generated attention graph. Specifically, the author utilizes two one-dimensional global pooling operations to aggregate input features along both vertical and horizontal directions into two independent direction-aware feature maps. These two feature maps, embedded with specific directional information, are then encoded into two attention maps, each capturing long-range dependencies along a spatial direction in the input feature map. Consequently, positional information is preserved within the generated attention graphs, which are subsequently multiplied onto the input feature map to enhance its representation capabilities. A coordinate attention module can be considered as a computational unit enhancing feature representation capabilities. It takes any intermediate tensor X as input and outputs an output Y of the same size with enhanced representation capabilities. The CA module encodes channel relationships and long-range dependencies through precise positional information, similar to the SE module, which also consists of two steps: coordinate information embedding and coordinate attention generation. Firstly, let's look at the coordinate information embedding part. Global pooling is often used in channel attention for global encoding spatial information into channel descriptors, making it difficult to preserve positional information. To facilitate the attention module in capturing spatial long-range dependencies with precise positional information, the author decomposes global pooling into one-to-one dimensionality feature encoding operations. Specifically, for the input X, a pooling kernel of (H, 1) and (1, W) is used along the horizontal and vertical coordinates to encode each channel. Subsequently, to better utilize the representations generated by the above coordinate information embedding module with a global receptive field and precise positional information, the coordinate attention generation operation is designed, which generates attention maps.

[Common Issues Summary]
Question: Why does the map of my model's epoch display as 0 or have very low accuracy?
Answer: Due to the source code being improved, it is not possible to directly fine-tune from the official model. Instead, training from scratch is required, which will result in weaker learning of features and requires many epochs for effects to emerge. Moreover, since the improved source code framework may not necessarily guarantee surpassing the official accuracy, there is also a possibility of achieving far worse results or even very low precision. This indicates that the improved framework does not yield good results. Therefore, for framework improvements, it merely provides a viable solution. Whether the improvements can lead to excellent performance still needs to be confirmed based on actual training conditions. Of course, this does not rule out the possibility of dataset issues, such as a single dataset, unbalanced sample distribution, limited generalization scenarios, poor annotation quality, and small detection targets among other reasons.
[Important Notice]
We only offer one improvement framework solution, and we do not guarantee that it will achieve excellent training accuracy or even surpass the accuracy of official models. The improvement framework is actually a complex process including the feasibility of the framework principle, whether the training dataset is appropriate, the need for back-propagation validation, as well as the comparison of parameter results from similar frameworks.
